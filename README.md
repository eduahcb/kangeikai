# Kangeikai

*[Leia em português](README.pt-BR.md)*

Open-source virtual space where people move around a shared 2D map and talk to whoever is
nearby — voice and video connect automatically based on proximity, no need to manually open a
call.

## About the name

**歓迎会** (*kangeikai*) is Japanese for "welcome party" — a gathering held to welcome someone
new.

Pronunciation: **kan-gay-kai** (roughly /kaŋ.ɡeɪ.kaɪ/)

## Status

MVP in active development. See [`docs/mvp-plan.md`](docs/mvp-plan.md) for the MVP scope and
stack.
